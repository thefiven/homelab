# Security policy

## Reporting a vulnerability

Report privately through GitHub's
[private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability)
on this repository, not through a public issue. This covers two kinds of
finding:

- A classic vulnerability: a flaw in this repository's configuration or
  automation that could be exploited.
- A leaked real-world designator: a hostname, IP address, or hardware
  identifier that should have stayed behind the placeholder convention
  described in [ADR-0001](./docs/adr/0001-public-repository-publication-policy.md)
  but slipped into the repository or its history.

## Response time

No specific response time is promised. This is a solo-maintained repository.
