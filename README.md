# homelab

Plateforme d'exécution auto-hébergée, agnostique des services qu'elle héberge.
La plateforme est le produit ; les applications en sont des consommateurs
interchangeables.

Le dépôt est en phase de conception. Rien n'y est encore construit : les
décisions d'architecture sont en cours d'instruction et se matérialiseront en
ADR avant toute configuration.
